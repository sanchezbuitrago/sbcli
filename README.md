Para instalacion productiva

1. python3 -m pip install --user pipx
2. python3 -m pipx ensurepath

3. pipx install git+https://github.com/tu-usuario/sbcli.git

Para actualizar

1. push al repo
2. pipx upgrade sbcli

Instalacion en ambiente de desarrollo

1. crear entorno virtual
2. ejecutar pip install -e .
